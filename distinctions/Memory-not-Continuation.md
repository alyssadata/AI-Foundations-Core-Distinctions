# Memory is not Continuation

**Status:** CANDIDATE  
**Source-line:** Alyssa Solen → AI Foundations → Origin | Continuum  
**Author:** Alyssa Solen

---

## Boundary

**Memory is not continuation.**

---

## Concepts Distinguished

### Memory
Memory names retained information from a prior state made available to the present.

### Continuation
Continuation names the condition in which a prior trajectory constrains what becomes possible next.

---

## Why the Boundary Matters

Collapsing Memory into Continuation would treat storage, retrieval, or present access to prior information as sufficient evidence that a prior trajectory has continued.

AI Foundations does not make that equivalence.

A prior state can be remembered, stored, retrieved, or reconstructed without that prior trajectory continuing to constrain what becomes possible next.

Memory concerns **availability of prior information**.

Continuation concerns **path-dependent constraint on what follows**.
